Beken Armino AI Solution
=====================================

:link_to_translation:`zh_CN:[中文]`

This is the official documentation for the Beken BK AI Solution development framework.

The BK AI Solution is developed based on BK AVDK SMP (Armino SMP SDK). It builds on that platform to provide AI application capabilities and reference projects for developers.

For BK AVDK SMP documentation, see `Armino SMP (English) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/en/v3.1.1/index.html>`_ or `Armino SMP (中文) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/zh_CN/v3.1.1/index.html>`_.
