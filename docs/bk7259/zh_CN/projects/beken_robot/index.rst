BK7259 机器人工程
=================================

:link_to_translation:`en:[English]`

1. 简介
---------------------------------

    本工程（``projects/beken_robot``）基于 BK7259 主控与 BK AVDK SMP v4.0.x，采用 **端 → 声网 Agora RTC → 云端 AI Agent** 的架构，提供机器人产品形态的完整参考实现。

    支持 360x390 MIPI LCD + LVGL UI（10 个 Demo 页面）、双麦阵列、扬声器、MIPI CSI 摄像头、4 路按键、ToF / 环境光 / G-Sensor / NFC、LED 指示灯、震动马达、舵机等外设。

    支持端侧 AEC / NS、本地命令词唤醒（你好博通 / 再见博通）、提示音播放，并通过声网 Agora Conversational AI Agent 接入主流大模型（OpenAI、豆包、DeepSeek、火山方舟等）。

        * 输出：扬声器、LED 指示灯、震动马达、舵机
        * 传感器：ToF、环境光、G-Sensor、NFC（视硬件版本）
        * 存储：SD-NAND（资源文件）+ 内置 partitions
        * 联网：板载 WiFi/BLE，预留 USB 接口的 4G Cat.1 模组

    * **软件特性**：

        * LVGL（10 个 Demo 页面，覆盖开机首页 / 主菜单 / 配网 / 声源定位 / AI 对话 / 视觉识别 / 命令词 / 音乐 / 音量等）

        * 音频：OPUS（推荐）、PCM
        * 视频：H.264 / JPEG（视觉模式）
        * 网络：WiFi STA、BLE 配网（BK App）
        * AI：声网 Agora RTC + Conversational AI Agent（语音 / 视觉双模）
        * 工厂配置、OTA、电池监控、低电告警等通用能力

1.3 按键
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

1.3.1 V1 板按键硬件特别说明（必读）
+++++++++++++++++++++++++++++++++++++++++++++++

BK7259 机器人 V1 板的按键存在以下硬件特殊情况，请测试 / 开发同事提前知悉，以免误判为软件缺陷：

- **原始设计**：4 个按键全部使用 ADC 按键方案，每个按键独立可识别短按 / 双击 / 长按。
- **V1 板实际**：由于原理图接线错误，只有一组（2 个）ADC 按键工作正常；另外两个 ADC 按键的功能改用一个独立的 GPIO 单按键替代：通过该 GPIO 按键的「短按」与「长按」分别承担原来两个 ADC 按键的功能。
- **结果**：4 个物理按键中只有 3 个真正起作用，属硬件已知问题，不作为测试缺陷上报。

因此在 V1 硬件上，可用的功能按键为 **S2 / S4 / S5**。

1.3.2 按键功能映射表
+++++++++++++++++++++++++++++++++

+--------------+----------+--------------------+--------------------------------------------+
| 物理按键     | 操作动作 | 对应功能           | 测试时的预期反馈                           |
+==============+==========+====================+============================================+
| S4           | 短按     | 确认 / 进入下一页  | 当前高亮项被确认；屏幕跳转到下一级菜单     |
+--------------+----------+--------------------+--------------------------------------------+
| S4           | 双击     | 返回 / 上一页      | 屏幕返回上一级菜单；当前页资源被释放       |
+--------------+----------+--------------------+--------------------------------------------+
| S5           | 短按     | 上一项 / 焦点左移  | 高亮焦点切换到上一个按钮，循环遍历         |
+--------------+----------+--------------------+--------------------------------------------+
| S2           | 短按     | 下一项 / 焦点右移  | 高亮焦点切换到下一个按钮，循环遍历         |
+--------------+----------+--------------------+--------------------------------------------+
| S3 (V1 废)   | 任意     | 无功能（V1 已知）  | 按下无任何反馈，不计入测试缺陷             |
+--------------+----------+--------------------+--------------------------------------------+
| S1           | 短按     | 复位（CEN）        | 系统硬复位                                 |
+--------------+----------+--------------------+--------------------------------------------+

1.3.3 按键开发说明
+++++++++++++++++++++++++++++++++

    1. GPIO 按键

        - 按键功能配置参考 ``components/bk_key_app/key_app_config.h`` 与 ``key_app_service.c``，开发者在该表中填写对应的 IO 管脚和按键回调事件即可。
        - 长按时长配置参考 ``multi_button.h`` 中的 ``LONG_TICKS`` 宏定义。
        - 当前所有按键事件转到任务中执行，如果按键回调被阻塞或执行时间过长，会影响按键响应速度。

    2. GPIO 按键注意事项

        - 请确认 GPIO 管脚仅供按键使用，否则同一管脚功能冲突会导致按键无效。
        - 客户开发板若 GPIO 与本工程不同，请按硬件设计重新配置；GPIO 使用方法可参考 ``bk_avdk_smp/ap/docs/bk7259/zh_CN/api-reference/peripheral/bk_gpio.rst``。
        - UI 按键到 LVGL 焦点 / 跳转的桥接代码见 ``projects/beken_robot/ap/src/ui_key_bridge.c`` 与 ``ui_nav_router.c``。

1.5 唤醒词
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

    1. ``你好博通`` 用于唤醒，本地端侧响应后通知应用层（``APP_EVT_ASR_NIHAOBOTONG``），UI 切到 LISTENING / SPEAKING 等状态，与云端 AI 互动。
    2. ``再见博通`` 用于结束对话，本地端侧响应后通知应用层（``APP_EVT_ASR_ZAIJIANBOTONG``），UI 进入空闲。

2.4 配网（BLE 通道）
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

2.4.1 首次配网
+++++++++++++++++++++++++++++++++

1. 主菜单焦点定位到 [配 网] → 短按【确认】键，进入 BLE 配网页（page_4）；
2. 焦点定位到 [开始] → 短按【确认】键，串口出现 ``Start provisioning (short press S4 to trigger)``，设备开始 BLE 广播；
3. BK App 在 5 秒内扫描到 ``BK_xxxxxx`` 设备 → 选择目标 WiFi 并填写密码 → 点击 ``开始配网``；
4. 60 秒内完成入网，串口出现 ``PROVISIONING_SUCCEED``，主菜单右上角自动出现 WiFi 图标；
5. 失败时 BK App 会提示密码错误 / SSID 不存在 / 信号弱等原因，设备应优雅退出配网模式。

2.4.2 重新配网
+++++++++++++++++++++++++++++++++

.. warning::

    重新配网之前，需要在 BK App 上把原绑定设备移除，然后重复 2.4.1 步骤。

2.5 AI 对话与视觉识别
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

3.2 主要配置（Kconfig）
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

    打开声网功能库需要在 ``cpu0`` 上打开以下配置：

    +----------------------------------------+----------------+---------------+----------------+
    | Kconfig                                |   CPU          |   Format      |      Value     |
    +----------------------------------------+----------------+---------------+----------------+
    | CONFIG_AGORA_IOT_SDK                   |   CPU0         |   bool        |        y       |
    +----------------------------------------+----------------+---------------+----------------+

    打开 BK 配网及 Agent 启动需要在 ``cpu0`` 上打开以下配置：

    +----------------------------------------+----------------+---------------+----------------+
    | Kconfig                                |   CPU          |   Format      |      Value     |
    +----------------------------------------+----------------+---------------+----------------+
    | CONFIG_BK_SMART_CONFIG                 |   CPU0         |   bool        |        y       |
    +----------------------------------------+----------------+---------------+----------------+

    打开 LVGL UI（MIPI 360x390）需要在 ``cpu1`` / ``cpu2`` 上打开以下配置：

    +----------------------------------------+----------------+---------------+----------------+
    | Kconfig                                |   CPU          |   Format      |      Value     |
    +----------------------------------------+----------------+---------------+----------------+
    | CONFIG_LVGL                            |   CPU1/2       |   bool        |        y       |
    +----------------------------------------+----------------+---------------+----------------+
    | CONFIG_LV_IMG_UTILITY_CUSTOMIZE        |   CPU1/2       |   bool        |        y       |
    +----------------------------------------+----------------+---------------+----------------+
    | CONFIG_LV_COLOR_DEPTH                  |   CPU1/2       |   int         |        16      |
    +----------------------------------------+----------------+---------------+----------------+
    | CONFIG_LV_COLOR_16_SWAP                |   CPU1/2       |   bool        |        y       |
    +----------------------------------------+----------------+---------------+----------------+

    工程级 Kconfig（``ap/Kconfig.projbuild``）：

    +----------------------------------------+----------------+---------------+----------------+
    | Kconfig                                |   CPU          |   Format      |      Value     |
    +----------------------------------------+----------------+---------------+----------------+
    | CONFIG_LDO3V3_ENABLE                   |   AP           |   bool        | n / y          |
    +----------------------------------------+----------------+---------------+----------------+
    | CONFIG_HARDWARE_SPEAKER_VER            |   AP           |   int (0~8)   | 0              |

3.3 BLE 配网及 Agent 定制指南
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

BLE 配网及 Agent 相关代码主要分布在 ``components/bk_smart_config`` 目录，客户可以参考如下说明定制自己的方案。

代码路径：``components/bk_smart_config/src/core/bk_smart_config_core.c``

- **进入 BLE 配网模式**：参考 ``bk_sconf_prepare_for_smart_config(void)``。
- **手机 App 通过 BLE 交互配网信息**：参考 ``bk_sconf_ble_msg_handler(ble_prov_msg_t *msg)``。
- **将 Agent 配置参数发送给手机 App**：参考 ``bk_sconf_send_agent_info(char *payload, uint16_t max_len)``。
- **解析服务器启动 Agent 参数**：参考 ``bk_sconf_prase_agent_info(char *payload, uint8_t reset)``。
- **启动 Agent 和 RTC**：参考 ``bk_sconf_start_network_transfer(char *device_id)``，会根据 RTC 后端（当前为 Agora）调用 ``bk_agora_start(device_id)``，同时启动 Agent 与 RTC（``components/network_engine/agora_rtc/agora_rtc_engine.c``）。
- **WiFi 连上后启动 Agent / 保存 wifi 与 Agent 信息**：参考 ``bk_sconf_network_provisioning_status_cb(...)``。
- **多模态切换（语音 ↔ 视觉）**：参考 ``bk_sconf_switch_ir_mode_handler(void)``，对 ``video_engine_init() / video_engine_deinit()`` 与 ``bk_sconf_upate_agent_info(device_id, "vision"|"text")`` 进行配对调用。

4.1 Agora RTC 调试命令
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

代码路径：``components/network_engine/agora_rtc/agora_rtc_engine.c``。

**基本格式**:

.. code:: bash

    agora_rtc <subcommand>

**子命令说明**:

    +----------------+--------+-------------------------------------------------+
    |子命令          |  说明  | 功能描述                                        |
    +----------------+--------+-------------------------------------------------+
    |start           |  必填  | 启动 RTC 和 Agent（同时启动）                   |
    +----------------+--------+-------------------------------------------------+
    |stop            |  必填  | 停止 RTC 和 Agent（同时停止）                   |
    +----------------+--------+-------------------------------------------------+
    |start_agora     |  可选  | 仅启动 RTC（不启动 Agent）                      |
    +----------------+--------+-------------------------------------------------+
    |stop_agora      |  可选  | 仅停止 RTC（不停止 Agent）                      |
    +----------------+--------+-------------------------------------------------+
    |start_agent     |  可选  | 仅启动 Agent（不启动 RTC）                      |
    +----------------+--------+-------------------------------------------------+
    |stop_agent      |  可选  | 仅停止 Agent（不停止 RTC）                      |
    +----------------+--------+-------------------------------------------------+

**使用说明**:

- 命令会自动使用设备 UID 作为 ``device_id`` （24 字节 UID 的十六进制字符串）。
- 使用 ``start`` / ``stop`` 命令时，会同时启停 RTC 和 Agent。
- 如需单独控制，可使用对应子命令。
- 使用此命令前需要确保已配置好 Agora 鉴权信息（``AGORA_APPID`` / ``AGORA_RESTFUL_TOKEN``），并且 PC 端可启动 AI Agent。

5. 常见问题
---------------------------------

Q：应用层没有 mic 数据上报？

A：本工程默认支持基于命令词的语音唤醒，只有唤醒后才会上报 mic 采集的数据到应用层，应用层再发给 AI 进行对话。如客户不需要语音唤醒功能，可通过宏 ``CONFIG_AE_SUPPORT_PROMPT_TONE`` 关闭。

Q：S3 按键按下没反应？

A：V1 板硬件已知问题，S3 因接线错误暂不工作。功能按键请使用 S2 / S4 / S5。

Q：进入 ``page_6`` / ``page_7`` 后状态一直停留在 CONNECTING？

A：先确认设备已成功配网（主菜单 WiFi 图标显示）；再确认 Agora ``AGORA_APPID`` / ``AGORA_RESTFUL_TOKEN`` 已正确配置且 PC 端 Agent 已启动；最后检查路由器是否能访问外网。

Q：基于 USB 接口已经适配的 4G Cat.1 模组有哪些？

A：广和通 LE270/370、合宙 Air780E、移远 EC-800M、移柯 I511 等。具体适配请参考 `BK Modem 文档 <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7259/zh_CN/v4.0.1/developer-guide/peripheral/bk_modem.html>`_。
