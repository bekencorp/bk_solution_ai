FAQ
--------------------------------

- **Where should ``SDK_DIR`` point?** To the root of the cloned **BK AVDK SMP** tree (where ``Makefile`` and ``tools`` live), not the BK AI repository root.
- **Missing toolchain or script errors?** Complete the environment setup in `Environment Deployment and Compilation <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/en/v3.1.1/get-started/index.html#smp-get-started-env>`_ first; for Docker, ensure Docker is installed and running.
- **Slow Docker image pull?** See the mirror / download options in `Environment Deployment and Compilation <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/en/v3.1.1/get-started/index.html#smp-get-started-env>`_.
