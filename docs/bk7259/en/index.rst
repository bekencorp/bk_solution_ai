Beken BK7259 Robot Solution
=====================================

:link_to_translation:`zh_CN:[中文]`

This is the official documentation for the Beken BK7259 Robot Solution development framework.

The solution is built on the BK7259 SoC and the **BK AVDK SMP (Armino SMP SDK) v4.0.x**. It provides a turn-key robot reference implementation covering an LVGL UI, local voice wake-word, Agora RTC AI voice / vision dialog, BLE provisioning, plus reference drivers for keys, display, mic, speaker, camera and a variety of sensors.

For BK AVDK SMP documentation, see `Armino SMP (English) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7259/en/v4.0.1/index.html>`_ or `Armino SMP (中文) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7259/zh_CN/v4.0.1/index.html>`_.
