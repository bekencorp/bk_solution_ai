常见问题
--------------------------------

- **``SDK_DIR`` 应指向哪里？** 指向已克隆的 **BK AVDK SMP** 仓库根目录（含 ``Makefile``、``tools`` 等），不是 BK AI 仓库根目录。
- **编译报错找不到工具链或脚本？** 先完成 `环境部署及编译 <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/zh_CN/v3.1.1/get-started/index.html#smp-get-started-env>`_ 中的环境部署；Docker 方式需本机已安装并启动 Docker。
- **国内网络拉 Docker 镜像较慢？** 请参阅 `环境部署及编译 <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/zh_CN/v3.1.1/get-started/index.html#smp-get-started-env>`_ 中的镜像 / 下载说明。
