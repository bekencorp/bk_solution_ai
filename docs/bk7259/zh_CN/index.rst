博通集成 BK7259 机器人方案
=====================================

:link_to_translation:`en:[English]`

	这是博通集成 BK7259 机器人方案开发框架的官方文档。

	本方案基于 BK7259 主控与 **BK AVDK SMP（Armino SMP SDK）v4.0.x**，提供机器人产品形态的完整端到云、云到大模型 AI 交互参考实现：包含 LVGL UI、本地语音唤醒、声网（Agora）RTC AI 对话与视觉问答、BLE 配网，以及按键 / 屏幕 / 麦克风 / 喇叭 / 摄像头 / 多种传感器的参考驱动。

	BK AVDK SMP 平台文档请参考 `Armino SMP（中文） <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7259/zh_CN/v4.0.1/index.html>`_ ；`英文文档 <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7259/en/v4.0.1/index.html>`_ 同步提供。
